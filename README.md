# Задание 1

## Задача 11

### Текст задачи

Первый массив, размерностью n х m, заполняется данными, вводимыми с клавиатуры, так что 
заполнение ведется по столбцам от последних элементов столбца к первым.  
Второй массив, размерностью n х n, заполняется случайными числами так, что в каждом столбце 
получается возрастающая последовательность элементов. 
Третий массив, размерностью n х n, заполняется для произвольного n так же, как для n=5:

<img width="221" height="137" alt="image" src="https://github.com/user-attachments/assets/f7f89f8d-01b9-4cdd-8476-2b319e476d77" />

### Алгоритм решения

Первый массив: Организовать цикл по столбцам (от последнего к первому) и внутри него вложенный цикл по строкам (снизу вверх, от $n-1$ до 0), считывая значения с клавиатуры через валидатор.
Второй массив: Заполнить случайными числами так, чтобы при переходе к каждой следующей строке в столбце значение строго увеличивалось (прибавлять случайный шаг к предыдущему элементу).
Третий массив: Заполнить матрицу последовательными простыми числами, проверяя каждое число на отсутствие делителей в диапазоне от 2 до его квадратного корня.

### Текст задачи

оценка которых больше 4.5.

### Алгоритм решения

Пройти циклом по каждой строке (каждому школьнику), вычислить сумму его оценок и найти среднее арифметическое. 
Если среднее арифметическое больше 4.5, вывести номер школьника и его средний балл.
